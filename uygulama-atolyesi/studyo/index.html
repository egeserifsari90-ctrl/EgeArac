GitHub’da APK nasıl oluşturulur?
  1. HTML indir ile index.html dosyanı kaydet.
  2. GitHub yükleme sayfasını aç. Dosyayı ekle ve Commit changes ile bu dala kaydet. Yüklediğin kod herkese açık depoda görünür.
  3. Derlemeleri aç. Başarılı çalıştırmada Artifacts → atolye-apk arşivini indir.
